# 第 0 课：先搞清“用什么代码写”

> 这是你的前台学习起点。后台参考实现即使已经继续开发，也不代表你需要现在一次性看懂它。

## 1. 答案：我们首先用 Python

这个项目的核心逻辑用 **Python** 编写，代码文件以 `.py` 结尾。选 Python 是因为：

- 它的基础语法对新手相对容易阅读；
- OCR、图像处理、数据评估和 LLM/VLM 的主流工具都有 Python 接口；
- 我们可以先用很小的普通函数学会逻辑，再慢慢加入图像和模型；
- 单元测试可以帮你立刻看到“这条规则到底写对没有”。

后面的本地网页会用少量 **HTML/CSS/JavaScript**，合成数据会用 **JSON**，文档会用 **Markdown**。你现在不需要同时学这些；第一个阶段只认 Python 和终端。

## 2. VS Code 和 Python 不是同一样东西

可以先这样理解：

- **VS Code** 是你写字和看文件的“工作台”；
- **Python** 是读取并执行 `.py` 代码的“执行器”；
- **Terminal（终端）** 是你向电脑输入命令的地方；
- **项目文件夹** 是保存代码、图片、测试和文档的位置。

例如，下面是应该写在 `.py` 文件里的 **Python 代码**：

```python
print("hello")
```

下面是应该输入 Terminal 的 **Shell 命令**：

```bash
python3 demo.py
```

它们不能随意对换位置。

## 3. 看懂“找不到文件”

如果 Python 报出：

```text
can't open file ... demo.py: [Errno 2] No such file or directory
```

说明 Python 没找到指定位置的 `demo.py`。常见原因是文件尚未创建、没有保存，或者终端所在目录不对；这条错误本身不是 Python 语法错误。

不同电脑上的项目路径不同。不要照抄别人的绝对路径，以自己保存代码的位置为准。

## 4. 现在只做一个动作

先不运行项目，也不安装任何东西。在 VS Code 下方 Terminal 里只输入：

```bash
pwd
```

`pwd` 显示终端当前所在的文件夹。它应当是保存本项目 `README.md`、`demo.py` 和 `src/` 的那一层目录。

如果不是，先在 VS Code 中打开项目文件夹，再打开一个新终端，重新运行 `pwd`。路径中包含中文或空格没有关系。

到这里就停下。前台教学的第一个检查点只是：**你能让 Terminal 站到正确项目文件夹。**

## 5. 下一步会做什么（现在不用做）

当 `pwd` 正确后，我们才会一步一步做：

1. 用 `ls` 看到项目文件；
2. 用 `python3 --version` 确认 Python；
3. 打开一个只有几行的 Python 文件；
4. 亲手改一行、运行一次、再看一个小测试。

不会一下子让你写 OCR、状态机或 LLM API。我们的目标是：你最后能自己从空文件开始写出来，而不是只能复制一个已经完成的项目。
