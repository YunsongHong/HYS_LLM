# 6000 行来源、1000 个目标的开发实测

日期：2026-08-28。对象：`ASSISTED_REVIEW_V1` 的单列编号定位与 OCR 比较。状态：开发诊断，**不是实拍照片、独立确认集或真人试验**，没有“领先其他工具 5%”的结论。

## 数据和运行条件

- 60 张干净的合成 PNG，每侧 30 张、每张约 200 行。异常注入前每侧 6000 行；注入后左 6001 行、右 5999 行。
- 固定选取 1000 个目标：每隔 6 行一个，`P000001` 至 `P005995`。所有目标始终保留在分母中。
- 真值为 748 项相同、250 项不同、1 项右侧缺失、1 项左侧重复。数值差异规则是右侧增加 `0.01 kPa`，不是现实业务差异的随机样本。
- 实际运行本机 Tesseract 5.5.1，`eng`、PSM 6、置信门槛 70；Python 3.13.2、Pillow 12.2.0、macOS 26.6.2 arm64。
- OCR 只收到图片与固定配置，不收到生成器真值。人工记录数为 0；没有模拟 R1、自动作答或批准。

## 结果

| 机器状态 | 项数 |
| --- | ---: |
| SAME | 672 |
| DIFFERENT | 228 |
| UNCERTAIN | 51 |
| NOT_LOCATED | 48 |
| MULTIPLE_CANDIDATES | 1 |
| 总目标 | 1000 |

| 诊断指标 | 分子 / 分母 |
| --- | ---: |
| 两侧都有唯一候选 | 951 / 1000 |
| 两侧行位置和原值都符合生成器真值 | 949 / 1000 |
| 真差异被标为 DIFFERENT | 227 / 250（90.8%） |
| 有正确两侧原文支持的差异 | 226 / 250（90.4%） |
| 真差异被标为 SAME | 0 / 250 |
| 真相同被标为 DIFFERENT | 1 / 748 |

949 项含 51 项被门槛保守标为不确定的记录，不能说成“949 项已通过”。未形成原文支持差异的 24 项包括：12 项未定位、11 项不确定、1 项虽然标签不同但原文读错。48 项未定位中，只有 1 项是生成器故意删除；另外 47 项在图中确实存在。

机器完成状态为 `READY`，`can_finish=false`、`approval=false`，1000 条人工记录均为空。程序随后关闭并重开 SQLite，核对状态和目标数一致。图片生成约 9.23 秒、保存并冻结约 7.56 秒、OCR 约 142.52 秒；总计约 159.73 秒。这些是一次本机运行的墙钟时间，不是人工节时或公平的工具速度比较。

## 两个具体错字

| 目标 | 合成原值 A / A′ | OCR A / A′ | 影响 |
| --- | --- | --- | --- |
| P005413 | `154.13 kPa` / `154.13 kPa` | `164.13 kPa` / `154.13 kPa` | 唯一假差异 |
| P005431 | `154.31 kPa` / `154.32 kPa` | `164.31 kPa` / `154.32 kPa` | 标签碰巧正确，但原文错误，不计入支持召回 |

两个编号和行位置都正确，左值均将 `5` 误读为 `6`，置信分仍高于 70。提高置信门槛不一定能解决误读，还可能增加拒答；本轮没有根据这些答案反复调参或改分母。

## 如何复现

在已安装项目、Tesseract 和 `eng` 的环境，从仓库根目录运行：

```bash
python tools/benchmark_assisted.py \
  --output artifacts/assisted-scale-run \
  --rows 6000 --targets 1000 --rows-per-page 200
```

目录必须不存在。工具生成图片和真值、走实际工作区上传/索引、输出 `BENCHMARK.json` 与 `FULL_REPORT.json`，再验证重启恢复。`inputs/fixture.json` 保存生成规则、图像哈希、目标和已知行区域；它不是 OCR 的输入。文件保留在本机，不由脚本上传。

评估按目标 ID 关联结果。原文支持要求两侧值等于各自真值、图片名和候选行框的 Y 中心符合生成位置、机器状态为 DIFFERENT。它不是任意版面上的完整边框精度认证。`mismatches_and_structural_cases` 是风险检查清单，不是“错误数”；其中也包含按预期发现的缺失和重复。

开发集只有一个字体/版式家族；目标、差异规律和图像渲染高度相关。本页只报告描述性计数，不给出推断性置信区间或正式成功判定。真实照片的透视、反光、失焦、低分辨率、复杂列和中文都未被覆盖。比较其他工具还需遵守[比较协议](./COMPARISON_PROTOCOL.md)，不能拿这里的数字直接与别人的公开 benchmark 相减。
